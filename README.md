Animated Web App
This project is an animated web application that showcases various web design and development features. It includes interactive elements such as mouse followers, magnet effects, background videos, and scroll-triggered animations.

Project Structure
The project consists of the following files:

index.html: The main HTML file that contains the structure of the web application.
style.css: The CSS file that contains the styles for the web application.
script.js: The JavaScript file that contains the interactive and animation logic.
Features
HTML
The index.html file includes the following sections:

Navigation Bar: A navigation bar with links and a menu icon.
Home Section: A hero section with a main heading and subheadings.
Featured Section: A section showcasing featured projects with images and descriptions.
Service Section: A section describing the services offered.
Boxes Section: A section with boxes containing images and descriptions.
Footer: A footer with copyright information.
CSS
The style.css file includes styles for various elements:

Global Styles: Basic styles for all elements, including margin, padding, and box-sizing.
Navigation Bar: Styles for the navigation bar and its elements.
Home Section: Styles for the hero section, including headings and paragraphs.
Featured Section: Styles for the featured projects section, including text and images.
Service Section: Styles for the service section, including headings and paragraphs.
Boxes Section: Styles for the boxes section, including images and tags.
Footer: Styles for the footer.
Media Queries: Responsive styles for different screen sizes.
JavaScript
The script.js file includes the following functionalities:

Mouse Follower: A mouse follower effect using the Shery.mouseFollower() function.
Magnet Effects: Magnet effects for elements using the Shery.makeMagnet() function.
Background Videos: Background videos for elements using the Shery.hoverWithMediaCircle() function.
Scroll-Triggered Animations: Animations triggered by scrolling using the gsap.to() function and ScrollTrigger.
Image Effects: Image effects using the Shery.imageEffect() function.
Dependencies
The project uses the following external libraries:

Shery.js: A library for interactive and animation effects.
GSAP: A library for animations.
ScrollTrigger: A plugin for scroll-triggered animations.
Three.js: A library for 3D graphics.
ControlKit: A library for UI controls.
